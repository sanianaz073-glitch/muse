Generating QR… takes 10-30 seconds the first time.

  1. Open WhatsApp on the phone you want to link
  2. Settings → Linked devices → Link a device
  3. Scan this QR (a new one is generated every 20 seconds)

Linking WhatsApp on this same phone (can't scan a QR)? Enter your number to get a code.

WhatsApp kholen → Linked devices → Link a device → "Link with phone number instead" → Enter this 8-character code
